frontend/data/ancient_visualization_dataset.json 里，除了“有星官的点”，实际还包含这些内容：

1. stats
这是整包数据的统计信息，比如：

catalog_rows_loaded
catalog_rows_valid
constellation_points
constellation_groups
tautou_targets
也就是说，它不只是星表本身，还带了处理结果摘要。

2. catalog
这是主星表数据，里面每条记录不只是“星官点”，还包含很多现代天体参数，例如：

hip
ra_j2000
dec_j2000
mag
pmra
pmdec
parallax
radial_velocity
星官
ra_1054
dec_1054
这里面最关键的问题就是：
它既有古代相关信息，也有现代观测/运动修正后的结果，所以不能当作纯古代星图直接渲染。

3. constellations
这是星官连线数据。
每个星官是一组点，通常用于画连线，结构大致是：

name
style
points
其中 points 里又有：

ra
dec
hip
mag
这个才是更适合前端“只渲染古代部分”的核心图层。

4. constellation_points
这是星官点的扁平化列表。
和 constellations 相比，它更像是把所有星官点汇总成一张明细表，方便索引或统计。

5. tautou_targets
这是现代观测目标数据，不属于古代星表本体。
字段里能看到：

match_id
target_name
ra
dec
flux
flux_sigma
filter
你说“前端只用古代部分”，那这一块确实应该彻底排除。

6. options
这是绘图/处理参数配置，比如：

constellation_line_style
target_epoch
它属于元数据，不是星体数据本身。
