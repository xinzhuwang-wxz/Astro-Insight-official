# 二、这次要做的两块具体是什么

---

## 1）CMD / HR Diagram

你文档里写的是：

- CMD：
  - `bp_rp`
  - `phot_g_mean_mag`
  - HSC `g-r`
  - `g` 波段 magnitude
- HR：
  - `teff_gspphot`
  - 绝对星等 `M_G = G - 5*log10(distance/10)`
- 清洗条件：
  - `parallax_error > 2σ` 剔除
  - `teff` 缺失剔除
- 扩展：
  - 3D CMD 加 `parallax`

### 这块我建议实现成
一个“**恒星演化分析模块**”，包含：

- **CMD 2D 图**
  - X：`bp_rp`
  - Y：`phot_g_mean_mag` 或 `g_mag`
  - 颜色：`mh_gspphot` 或金属丰度类字段
  - 点大小：误差或置信度相关字段

- **HR 2D 图**
  - X：`teff_gspphot`（反向）
  - Y：`M_G`
  - 用颜色区分演化阶段或数据质量

- **3D CMD**
  - X：`bp_rp`
  - Y：`G`
  - Z：`parallax`
  - 用 Plotly 做交互式三维展示

- **样本点击详情**
  - Gaia/HSC 全参数
  - 演化阶段标注
  - 数据质量提示

---

## 2）自行与径向速度可视化

你文档里写的是：

- 统一运动参数：
  - `pmRA/pmDE/RV`
  - `pmra/pmdec/radial_velocity`
- 天球投影：
  - RA/Dec → 赤平投影
- 速度归一化
- 2D 矢量图：
  - 底图 HSC 光学图像
  - 箭头表示自行方向
  - 颜色表示径向速度
- 速度场动画：
  - `apply_space_motion`
  - 1000 年前后位置变化
- 异常检测：
  - 3σ 标记异常值

### 这块我建议实现成
一个“**动力学运动分析模块**”，包含：

- **2D 矢量场图**
  - 底图可以先用平面坐标网格或天球背景
  - 箭头长度表示自行大小
  - 箭头方向表示运动方向
  - 颜色表示径向速度正负

- **时间滑块动画**
  - 显示当前时刻
  - 计算 ±1000 年轨迹
  - 便于展示轨迹变化

- **异常点高亮**
  - 高自行/高径向速度对象单独标记
  - 右侧显示异常原因
