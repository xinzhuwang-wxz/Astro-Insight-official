# 面向技术实现的重构方案

> 目标：这是一份“可以据此复原项目”的技术实现文档。它尽量把项目结构、每个文件的语言、实现方式、功能、数据流、路由、接口、关键状态和重构建议都写清楚，方便其他人按文档重新搭建同等行为的系统。

---

## 1. 项目定位

这个项目是一个 **Next.js 前端应用 + CopilotKit 对话层 + Tauri 桌面壳** 的混合项目，核心交互围绕“天文日历、图片相册、模拟实验、分析报告、AI 对话动作”展开。

它的本质不是一个纯内容站，而是一个具有以下能力的交互式应用：

1. 用日历组织事件与导航
2. 用相册浏览图片与标签
3. 用模拟实验展示任务运行状态
4. 用 CopilotKit 将自然语言转成前端行为
5. 用 Tauri 兼容桌面端封装

如果要复原整个项目，最重要的是复原这条主链路：

**首页 / 日历 → 相册 → 模拟实验 → 分析报告 → Copilot 交互**

## 3. 运行时架构

### 3.1 核心运行时组成

项目在运行时主要由以下几层构成：

1. **页面层**：`src/app/*`
2. **组件层**：`src/components/*`
3. **数据层**：`src/lib/*`
4. **状态/行为层**：`useSerial`、Copilot 回调、自定义事件、localStorage
5. **服务层**：`src/app/api/*`
6. **桌面层**：`src-tauri/*`

### 3.2 关键交互链路

#### 主链路 A：日历导航

- 首页渲染 `CalendarSeptember`
- 事件点击后跳转到 `/album/[folder]`
- 相册第一张图可进入模拟实验
- 模拟实验可切换到分析报告

#### 主链路 B：Copilot 驱动

- 页面中挂载全局 `CopilotPopup`
- 用户输入特定语义后触发 `onMessageSent`
- 识别到美国天文事件相关语句时生成 mock 数据
- 通过 `localStorage + CustomEvent` 通知日历组件更新

## 6. 组件层说明

### 6.1 `src/components/CalendarSeptember.tsx`
- 语言：TypeScript / TSX
- 类型：客户端组件
- 依赖：`react`, `next/link`, `next/navigation`, `src/lib/calendar-data`
- 职责：
  - 渲染 9 月/10 月日历
  - 切换月份
  - 渲染图例筛选
  - 根据事件类别显示 icon
  - 点击日期进入相册
  - 接收美国天文事件更新事件

#### 实现方式

1. 通过 `useState` 保存当前月份
2. 调用 `getCalendarData(month)` 获取静态数据
3. 构建 `day -> events` 映射
4. 根据 `legendItems` 过滤可见事件
5. 通过 `useRouter()` 在点击事件时跳转到相册路由
6. 通过 `useEffect()` 监听 `refreshUSAstronomyData` 自定义事件
7. 通过 `localStorage` 读取缓存的美国天文事件

#### 关键交互

- 月份切换按钮：上月 / 下月
- legend 切换：控制类别显示
- 点击日期：若存在指定类别事件则跳转相册

---

### 6.2 `src/components/CalendarAlbum.tsx`
- 语言：TypeScript / TSX
- 类型：客户端组件
- 依赖：`SimulationExperiment`
- 职责：
  - 展示图片网格
  - 提供 Copilot 输出日志查看
  - 点击第一张图进入模拟实验

#### 实现方式

1. 使用 `useState` 保存日志展示状态
2. 点击“显示 Copilot 输出”时调用 `/copilot-last-output.json`
3. 遍历 `images` 数组构建图片网格
4. 图片右下角显示标签
5. 首图点击时切换到 `SimulationExperiment`

#### 关键逻辑

- 首图特殊处理：用于进入实验界面
- 标签映射：根据文件名查找 `labels` 对象
- 图片打开：其他图片使用新窗口或当前窗口打开

### 6.3 `src/components/SimulationExperiment.tsx`
- 语言：TypeScript / TSX
- 类型：客户端组件
- 职责：
  - 模拟多个实验任务运行
  - 展示状态、进度、准确率
  - 切换到分析报告页

#### 实现方式

1. 用 `useState` 初始化实验列表
2. `startExperiment(id)` 将一个实验设为 running
3. 使用 `setTimeout()` 模拟训练完成
4. 计算随机准确率
5. `ExperimentCard` 子组件负责单卡展示
6. 运行时通过 `useEffect()` 控制进度条增长

#### 设计意图

这是一个“前端模拟训练台”，可以直接改造成：

- 数据分析任务
- 批处理任务
- 模型训练任务

## 12. 数据流复原说明

### 12.1 日历数据流

```text
CalendarSeptember
  -> getCalendarData(month)
  -> 生成事件映射
  -> 点击日期
  -> 判断 category/title
  -> router.push('/album/HB?day=...')
```

### 12.2 Copilot 数据流

```text
用户输入消息
  -> CopilotPopup onMessageSent
  -> 正则识别关键语义
  -> 构造 mockUSAstronomyData
  -> localStorage.setItem(...)
  -> window.dispatchEvent(CustomEvent)
  -> CalendarSeptember 监听并更新
```

### 12.3 相册数据流

```text
app/album/[folder]/page.tsx
  -> fs.readdirSync(public/images/{folder})
  -> 过滤图片文件
  -> 读取 gz2_label_slice.csv
  -> 构建 labelsMap
  -> 传入 CalendarAlbum
```

### 12.4 Copilot 输出流

```text
/api/copilotkit
  -> 运行 OpenAI/CopilotRuntime
  -> onAfterRequest
  -> 提取 outputMessages
  -> 写入内存 + JSON 文件
  -> /api/copilotkit/last-output 读取
```

## 15. 面向你后续升级的建议

如果你要把它升级成数据探索性分析与可视化项目，最适合保留的结构是：

- **时间维度**：日历
- **对象维度**：图像/样本/文件
- **过程维度**：实验/任务/分析流程
- **交互维度**：CopilotKit 对话动作

建议未来把这套实现改造成以下通用域模型：

- `Dataset`
- `Record`
- `TimeWindow`
- `ExplorationTask`
- `Insight`
- `ConversationAction`

这样就可以把“天文事件 + 相册 + 实验”自然迁移成“数据集 + 视图 + 分析任务”。

## 17. 结论

这份项目的实现核心不是某个单独页面，而是三层结构的组合：

1. **日历导航层**：把内容组织成时间驱动的入口
2. **相册/实验层**：把对象浏览与任务执行串起来
3. **Copilot 动作层**：让自然语言可以直接影响前端状态

只要保留这三层结构，再替换具体领域数据，就可以把这个项目迁移成一个新的数据探索和可视化应用。
